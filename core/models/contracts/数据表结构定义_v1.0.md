# PID 智能整定 — OS 语义层表结构定义（交付文档）

> **版本**：v2.0  
> **更新日期**：2026-04-08  
> **交付方**：PID Agent 算法组  
> **接收方**：HolliCube OS 中台团队  

---

## 概述

PID 智能整定需要 OS 中台提供 **6 张语义表 + 6 个 REST API**。本文档定义每张表的字段名、类型、含义和示例值，供 OS 中台建表和开发接口使用。

### 表清单

| 序号 | 表名 | 中文名 | 更新频率 | 数据来源 |
|:---|:---|:---|:---|:---|
| 1 | `os_ontology` | 本体模型（设备台账） | 静态 | ERP / 设备管理系统 |
| 2 | `os_mechanism` | 机理模型（过程物理特性） | 静态 | 算法侧预定义 + 工艺确认 |
| 3 | `os_knowledge` | 知识模型（专家整定约束） | 静态 | 算法侧预定义 + 工艺确认 |
| 4 | `os_characterization` | 表征模型（动态运行特征） | **按需计算** | OS 从历史库实时计算 |
| 5 | `os_data_mapping` | 数据映射（DCS 点位） | 静态 | DCS 组态 |
| 6 | `os_metrics` | 指标模型（控制绩效 KPI） | 按需/定期 | OS 统计计算 |

## 表 1：os_ontology（本体模型 — 设备台账）

**主键**：`device_id`  
**API**：`GET /api/v1/ontology/{device_id}`

| `tank_cross_section_m2` | float | | 储罐截面积（m²） | `12.5` |
| `valve_cv_max` | float | | 阀门最大流量系数 Cv | `60.0` |
| `valve_type` | string | | 阀门特性：`linear` / `equal_percentage` | `"equal_percentage"` |
| `plant` | string | | 所属装置 | `"2216"` |

## 表 2：os_mechanism（机理模型 — 过程物理特性）

**主键**：`loop_type`（不同回路类型的机理不同）  
**API**：`GET /api/v1/mechanism/{loop_type}`

> 不同回路的机理值差异见下方**附表 A**。

### 一、物理规则

| 字段名 | 类型 | 必填 | 说明 | 示例值 (level) |
|:---|:---|:---|:---|:---|
| `process_nature` | string | ✅ | 过程性质：`self_regulating`（自衡）/ `integrating`（积分） | `"integrating"` |
| `process_gain_sign` | int | ✅ | 固有增益符号：`+1` 正作用 / `-1` 反作用 | `1` |
| `dead_time_dominant` | bool | ✅ | 是否为大纯滞后系统 | `false` |
| `coupling_risk` | string | | 耦合风险：`none` / `low` / `medium` / `high` | `"medium"` |
| `nonlinearity_type` | string | | 非线性类型：`none` / `valve_saturation` / `valve_nonlinear` / `process_nonlinear` | `"valve_saturation"` |

### 二、仿真模拟

| 字段名 | 类型 | 必填 | 说明 | 示例值 (level) |
|:---|:---|:---|:---|:---|
| `preferred_simulation_model` | string | ✅ | 首选仿真结构：`FOPDT` / `SOPDT` / `FO_INTEGRATOR` | `"FO_INTEGRATOR"` |
| `allowed_simulation_models` | string[] | | 允许的备选模型列表 | `["FO_INTEGRATOR", "INTEGRATOR", "FOPDT"]` |
| `max_model_order` | int | | 最大允许建模阶数 | `1` |
| `typical_time_constant_range_s` | float[2] | | 典型时间常数范围（秒）[min, max] | `[10.0, 3600.0]` |
| `typical_dead_time_range_s` | float[2] | | 典型纯滞后范围（秒）[min, max] | `[0.0, 120.0]` |
| `natural_frequency_s` | float | | 自然振荡周期预估（秒） | `0.0` |

### 三、对象/约束建模

| 字段名 | 类型 | 必填 | 说明 | 示例值 (level) |
|:---|:---|:---|:---|:---|
| `state_variables` | string[] | | 过程状态变量名称 | `["liquid_level"]` |
| `mass_balance_constrained` | bool | | 是否受质量守恒约束 | `true` |
| `energy_balance_constrained` | bool | | 是否受能量守恒约束 | `false` |
| `output_physical_bounds` | float[2] | | PV 物理边界 [下限, 上限] | `[0.0, 100.0]` |
| `integrator_gain_range` | float[2] | | 积分增益范围（仅积分过程） | `[0.001, 0.5]` |

## 表 3：os_knowledge（知识模型 — 专家整定约束）

**主键**：`loop_type`（按回路类型维护，可被设备实例覆盖）  
**API**：`GET /api/v1/knowledge/{loop_type}`

### PID 参数约束

| 字段名 | 类型 | 必填 | 说明 | 示例值 (level) |
|:---|:---|:---|:---|:---|
| `pb_range` | float[2] | ✅ | 比例带安全范围 [PB_min, PB_max] | `[100.0, 1000.0]` |
| `gain_range` | float[2] | ✅ | 过程增益合理范围 [K_min, K_max] | `[0.01, 200.0]` |
| `td_enable` | bool | ✅ | 是否允许开启微分项 | `false` |
| `td_ratio` | float | | 微分/积分时间比例 | `0.0` |
| `td_max` | float | | 微分时间上限（秒） | `0.0` |
| `ti_max` | float | ✅ | 积分时间上限（秒） | `3600.0` |

### 整定策略

| 字段名 | 类型 | 必填 | 说明 | 示例值 (level) |
|:---|:---|:---|:---|:---|
| `tuning_strategy` | string | ✅ | `aggressive`（激进）/ `conservative`（保守） | `"conservative"` |
| `tau_c_factor` | float | ✅ | λ 调节系数（越大越保守） | `1.5` |
| `safety_factor` | float | ✅ | 安全余量系数 | `1.0` |
| `ti_multiplier` | float | | 积分时间附加乘数 | `1.2` |
| `integrating_mode` | bool | | 是否启用积分过程整定模式 | `true` |

### 质量阈值

| 字段名 | 类型 | 必填 | 说明 | 示例值 (level) |
|:---|:---|:---|:---|:---|
| `max_overshoot_percent` | float | ✅ | 最大允许超调量（%） | `40.0` |
| `settling_time_factor` | float | | 评分时对调节时间的加权因子 | `5.0` |
| `overshoot_discount` | float | | 超调折扣系数（评分用） | `2.5` |
| `oscillation_tolerance` | float | | 振荡容忍度阈值 | `0.4` |

### 知识图谱（规则 / 案例 / 专家经验）

> 这三个字段是**文本化的专家知识**，主要供大模型 Prompt 使用，常规算法不直接读取。

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|:---|:---|:---|:---|:---|
| `rules` | string[] | ✅ | 安全规则列表（硬性约束，算法+大模型都必须遵守） | `["液位回路严禁使用微分项（Td=0）", "OP 必须保持在 15%~85%"]` |
| `cases` | object[] | | 历史整定案例（条件→参数→效果） | 见下方示例 |
| `expert_experience` | string[] | | 工程师经验条目（非硬性，大模型推理参考） | `["液位控制的核心目标是平稳，不是快速"]` |
| `historical_best_kp` | float | | 历史最佳 Kp | `0.35` |
| `expert_notes` | string | | 简短经验备注（向后兼容） | `"液位回路：积分过程，平滑控制"` |

**cases 示例结构**：
```json
{
    "condition": "大滞后温度回路 + 震荡工况",
    "suggested_params": {"Kp": "0.7~0.9", "Ti": "150~200s", "Td": "25~35s"},
    "effect": "稳态率 ≥ 95%, 超调 ≤ 3%"
}
```

## 表 4：os_characterization（表征模型 — 动态运行特征）

**主键**：`device_id` + `timestamp`  
**API**：`GET /api/v1/characterization/{device_id}?hours=48`

> ⚠️ **这是唯一需要实时计算的表**。OS 中台在收到请求后，从历史库拉取最近 48h 的 PV/MV 时序数据，调用计算逻辑后返回。计算参考代码见 `features/feature_calculator.py`。

### 基础字段

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|:---|:---|:---|:---|:---|
| `device_id` | string | ✅ | 设备 ID | `"2216_LIC_50104"` |
| `timestamp` | string | ✅ | 计算时间（ISO 8601） | `"2026-04-08T10:00:00Z"` |

### signal（信号表征）

| 字段名 | 类型 | 范围 | 说明 | 计算方法 |
|:---|:---|:---|:---|:---|
| `oscillation_ratio` | float | 0-1 | PV 振荡比例，越大越振荡 | PV 导数符号反转次数占比 |
| `dominant_period_s` | float | ≥0 | 主振荡周期（秒），0=无振荡 | 自相关法估算 |
| `noise_level` | float | 0-1 | 高频噪声强度 | 移动平均残差/量程 |
| `linearity_index` | float | 0-1 | 线性度，1=完全线性 | 分段增益一致性 |

### valve（阀门表征）

| 字段名 | 类型 | 范围 | 说明 | 计算方法 |
|:---|:---|:---|:---|:---|
| `stiction_index_estimated` | float | 0-1 | 阀门卡涩指数 | MV动PV不动的窗口占比 |
| `deadband_estimated` | float | 0-100 | 死区估计（%MV量程） | MV反向切换响应距离 |
| `reversal_error` | float | 0-1 | 回程误差 | 正/反向增益差异比 |

### performance（控制绩效）

| 字段名 | 类型 | 范围 | 说明 | 数据来源 |
|:---|:---|:---|:---|:---|
| `performance_score_avg` | float | 0-10 | 综合控制评分 | **算法计算**（见参考代码） |
| `auto_mode_time_ratio` | float | 0-1 | 自动模式时间占比 | **OS 从 DCS 历史统计** |
| `intervention_count_daily` | int | ≥0 | 日均人工干预次数 | **OS 从操作日志统计** |
| `recent_step_events` | int | ≥0 | 近期有效 MV 阶跃次数 | **算法计算**（见参考代码） |

### llm_extra_features（扩展特征）

| 字段名 | 类型 | 说明 |
|:---|:---|:---|
| `llm_extra_features` | object | 预留的 Key-Value 扩展字段，后续大模型若需新特征在此追加 |
