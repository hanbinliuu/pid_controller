## 模块职责划分

### 1. **数据分析模块** (`data/analyzer.py`)
- **类**: `DataAnalyzer`
- **职责**:
  - CASE分类 (`classify_case`)
  - 稳态检测 (`is_steady_state`)
  - 设定值变化检测 (`detect_setpoint_changes`)
  - 扰动检测 (`find_disturbance_start`)
  - 整定段提取 (`extract_tuning_segment`)

### 2. **数据预处理模块** (`data/preprocessor.py`)
- **类**: `DataPreprocessor`
- **职责**:
  - 场景检测 (`detect_control_scenario`)
  - 模型类型检测 (`detect_model_type`)
  - 控制模式检测 (`detect_control_mode`)
  - 温控数据预处理 (`preprocess_temperature_data`)
  - 液位数据预处理 (`preprocess_level_data`)

### 3. **模型辨识模块** (`model/identifier.py`)
- **类**: `ModelIdentifier`
- **职责**:
  - FOPDT模型辨识 (`identify_fopdt`)
  - 二阶模型辨识 (`identify_second_order`)
  - 积分-延迟模型辨识 (`identify_integral_delay`)
  - 带热损失FOPDT辨识 (`identify_fopdt_with_heat_loss`)
  - 参数初始值估计 (`estimate_initial_guess_from_operational_data`)

### 4. **PID整定模块** (`pid/tuner.py`)
- **类**: `PIDTuner`
- **职责**:
  - Lambda整定 (`lambda_tuning`)
  - 温控Lambda整定 (`lambda_tuning_for_temperature_control`)
  - 液位Lambda整定 (`lambda_tuning_for_level_control`)
  - 流量Lambda整定 (`lambda_tuning_for_flow`)
  - Cohen-Coon整定 (`cohen_coon_tuning`)

### 5. **整定逻辑模块** (`tuning/logic.py`)
- **类**: `SystemTuningLogic`
- **职责**:
  - CASE类型检测 (`detect_case_type`)
  - 分段稳态检查 (`check_segment_steady_state`)
  - 振荡检测 (`_check_oscillation`)
  - SV变化后稳态检查 (`_check_final_steady_after_sv_change`)

### 6. **系统辨识与整定集成模块** (`tuning/identifier.py`)
- **类**: `SystemIdentifier`
- **职责**:
  - 统一入口 (`auto_identify_from_json`)
  - 自动整定 (`auto_tune_from_json`)
  - 多段整定 (`_tune_multiple_segments`)
  - 单段整定 (`_tune_single_segment`)
  - 使用组合模式整合所有功能模块

### 7. **PID评估模块** (`pid/evaluator.py`)
- **类**: `PIDEvaluator`
- **职责**:
  - PID性能评估 (`evaluate`)
  - 稳态误差计算
  - 振荡指标计算
  - 控制平滑性评估
  - 综合评分和等级评定

### 8. **稳定性检测模块** (`model/stability/detector.py`)
- **类**: `StabilityDetector`
- **职责**:
  - 稳态判断 (`is_steady_state`)
  - 非稳态段检测 (`detect_non_steady_segments`)
  - 设定值分段 (`detect_setpoint_segments`)
  - 扰动起始点定位 (`find_disturbance_start`)

## 数据流向图

```
JSON数据 (timestamp, pv, mv, sv)
    │
    ├─> 数据解析和验证
    │
    ├─> 设定值变化检测 ──> 数据分段
    │
    ├─> 各段稳态检查 ──> 确定需要整定的段
    │
    └─> 对每个需要整定的段:
        │
        ├─> 场景检测 (temperature/level/flow)
        │
        ├─> 数据预处理 (去噪、滤波、平滑)
        │
        ├─> 模型类型检测 (fopdt/second_order/...)
        │
        ├─> 模型参数辨识 (K, T, L)
        │   ├─> 初始值估计
        │   ├─> 非线性优化
        │   └─> 参数限幅
        │
        ├─> 控制模式检测 (STANDARD/ANTI_NOISE/...)
        │
        └─> PID参数整定 (Pb, Ti, Td)
            ├─> Lambda方法 或 Cohen-Coon方法
            ├─> 场景特定调整
            ├─> 模式特定调整
            └─> 参数限幅和保护
```

## 关键算法说明

### 1. CASE分类逻辑 (classify_case)
- **CASE_1**: 冷启动，一开始就是非稳态
- **CASE_2**: 设定值手动调整，调整过程不算非稳态
- **CASE_3**: 旧参数下稳态，后期出现非稳态
- **ALREADY_STABLE**: 全程稳态，无需整定

### 2. 分段整定策略
1. 检测设定值变化点，将数据分段
2. 检查每段的稳态情况
3. 从第一个非稳态段开始整定
4. 后续段使用前一段的参数仿真，判断是否需要整定

### 3. 模型辨识方法
- **初始值估计**: 基于互相关分析、增益估计、响应速度
- **闭环辨识增强**: 利用SV和当前PID参数改进辨识精度
- **非线性优化**: 使用scipy.optimize.least_squares最小化残差

### 4. Lambda整定公式
```
Kp = (T + L/2) / (K * (λ + L/2))
Ti = T + L/2
Td = (T * L) / (2*T + L)
```
其中 λ 为调节参数，通常取 λ = 0.8*T

## 使用示例

```python
from tuning.identifier import SystemIdentifier

# JSON数据格式
json_data = {
    "data": [
        {"timestamp": 1761642000000, "pv": 5.0, "mv": 13.0, "sv": 5.0},
        # ... 更多数据点
    ]
}

# 调用主函数进行自动整定
result = SystemIdentifier.auto_identify_from_json(
    json_data=json_data,
    setpoint=None,  # 自动从数据中提取
    tuning_method=TuningMethod.LAMBDA
)

# 返回结果
if result is not None:
    print(f"新PID参数: Pb={result['pb']:.2f}%, Ti={result['ti']:.2f}s, Td={result['td']:.2f}s")
    print(f"模型类型: {result['model_type']}")
    print(f"控制模式: {result['mode']}")
    print(f"场景类型: {result['scenario']}")
```

## 总结

**主函数**: `SystemIdentifier.auto_identify_from_json()`

**核心流程**:
1. 数据解析和验证
2. 设定值变化检测和分段
3. 各段稳态检查
4. 场景和模式自动检测
5. 数据预处理
6. 模型辨识
7. PID参数整定
8. 结果返回

**设计模式**: 组合模式 - `SystemIdentifier` 组合了所有功能模块，通过 `__getattr__` 实现方法代理

| 特性 | 原版本 | 优化版本 |
|------|--------|----------|
| 数据质量检查 | ❌ 无 | ✅ 8项检查 |
