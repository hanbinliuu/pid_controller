## 算法概述

本模块是一个完整的PID控制器自动整定系统，基于**FOPDT模型辨识**和**Lambda整定方法**，支持多种工业控制场景（温度、液位、流量）。系统采用**组合设计模式**，集成了数据分析、模型辨识、参数整定、质量检查等多个功能模块。

### 核心特性
- ✅ 自动场景识别（温度/液位/流量）
- ✅ 多种模型辨识（FOPDT/二阶/积分延迟/带热损失FOPDT）
- ✅ 智能分段整定（支持设定值变化场景）
- ✅ 数据质量预检（8项检查）
- ✅ 参数验证机制（5层验证）
- ✅ 性能评估功能

## 主函数说明

### 主入口函数

#### `SystemIdentifier.auto_identify_from_json()`
**文件位置**: `tuning/identifier.py` (第530-629行)

**功能**: 从JSON数据自动识别模型类型和控制模式，并完成PID整定

**参数**:
```python
def auto_identify_from_json(json_data, setpoint=None, tuning_method=TuningMethod.LAMBDA,
                           mode=None, auto_detect=True, enable_setpoint_segmentation=True,
                           current_pid_params=None, enable_quality_check=True,
                           enable_param_validation=True, enable_performance_eval=False)
```

**返回值**:
```python
{
    'pb': float,              # 比例带 (%)
    'ti': float,              # 积分时间 (s)
    'td': float,              # 微分时间 (s)
    'model_type': str,        # 模型类型
    'model_params': dict,     # 模型参数 {K, T, L}
    'scenario': str,          # 场景类型
    'mode': str,              # 控制模式
    'validation': dict,       # 参数验证结果（可选）
    'performance': dict       # 性能评估结果（可选）
}
```

### 核心整定函数

#### `SystemIdentifier.auto_tune_from_json()`
**文件位置**: `tuning/identifier.py` (第53-220行)

**功能**: 根据数组数据自动整定PID参数，支持分段整定

**核心步骤**:
1. 数据质量预检（8项检查）
2. 场景和模式检测（缓存结果）
3. 设定值变化检测和分段
4. 各段稳态检查
5. 执行整定（多段或单段）
6. 参数验证和性能评估

## 详细算法说明

### 1. Lambda整定算法

**算法原理**:
Lambda整定是一种基于模型的PID参数整定方法，通过调节参数λ来平衡控制系统的快速性和稳定性。

**核心公式**:
```
对于FOPDT模型: G(s) = K * e^(-Ls) / (Ts + 1)

PID参数计算:
Kp = (T + L/2) / (K * (λ + L/2))
Ti = T + L/2
Td = (T * L) / (2*T + L)

其中:
- K: 系统增益
- T: 时间常数
- L: 纯滞后时间
- λ: 调节参数，通常取 λ = 0.8*T
```

**场景调整**:

1. **温度控制**:
   - 如果 L/T > 0.5 (大滞后系统):
     - Kp *= 0.85 (降低增益，提高稳定性)
     - Ti *= 1.15 (增大积分时间，减缓积分作用)
     - Td *= 0.9 (略微减小微分)
   - 如果 L/T > 0.3:
     - Kp *= 0.9
     - Ti *= 1.1

2. **液位控制**:
   - Kp *= 0.7 (液位控制需要更保守)
   - Ti *= 1.3 (积分作用更缓慢)
   - Td = 0 (通常不使用微分)
   - 如果 T > 50 (积分系统):
     - Kp *= 0.6
     - Ti = T * 1.5

3. **流量控制**:
   - Kp *= 0.6 (快速响应系统)
   - Ti *= 1.5
   - Td = 0 (不使用微分)

**模式调整**:

1. **抗扰模式** (ANTI_DISTURBANCE):
   - Kp *= 0.8 (适当降低增益)
   - Ti *= 1.2 (增大积分时间)
   - Td *= 0.7 (减小微分作用)

2. **抗噪模式** (ANTI_NOISE):
   - Kp *= 0.7 (显著降低增益)
   - Ti *= 1.3 (增大积分时间)
   - Td *= 0.5 (显著减小微分)

### 2. FOPDT模型辨识算法

**算法步骤**:

1. **初始参数估计**:
   ```python
   # 1. 滞后时间估计（互相关分析）
   correlation = np.correlate(u - u_mean, y - y_mean, mode='full')
   lag_samples = np.argmax(correlation) - len(u) + 1
   L = lag_samples * dt_avg
   
   # 2. 增益估计
   K = (y_end - y_start) / (u_end - u_start)
   
   # 3. 时间常数估计（63.2%响应时间）
   target_value = y_start + 0.632 * (y_end - y_start)
   T = t_63.2% - t_start - L
   ```

2. **非线性最小二乘优化**:
   ```python
   # 目标函数: 最小化模型输出与实际输出的残差
   def residuals(params):
       K, T, L = params
       y_model = fopdt_model(params, t, u, y0)
       return y_measured - y_model
   
   # 使用scipy.optimize.least_squares求解
   result = least_squares(residuals, initial_guess, bounds=bounds)
   ```

3. **参数限幅**:
   ```python
   K = np.clip(K, K_min, K_max)
   T = np.clip(T, T_min, T_max)
   L = np.clip(L, L_min, L_max)
   ```

**FOPDT模型仿真**:
```python
def fopdt_model(params, t, u, y0):
    K, T, L = params
    y = np.ones_like(t) * y0
    L_samples = int(L / dt)
    
    for i in range(len(t)):
        u_delayed = u[max(0, i - L_samples)]
        dy = (K * u_delayed - (y[i-1] - y0)) / T * dt
        y[i] = y[i-1] + dy
    
    return y
```

### 3. 数据质量检查算法

**8项检查内容**:

1. **数据长度检查**:
   ```python
   if len(t) < 50:
       return False, "数据点数不足50个"
   ```

2. **PV变化检查**:
   ```python
   pv_range = np.max(pv) - np.min(pv)
   if pv_range < 0.1:
       return False, "PV变化范围过小"
   ```

3. **MV变化检查**:
   ```python
   mv_range = np.max(mv) - np.min(mv)
   if mv_range < 0.1:
       return False, "MV变化范围过小"
   ```

4. **信噪比检查**:
   ```python
   signal_power = np.var(pv)
   noise_power = np.var(np.diff(pv))
   snr = signal_power / noise_power
   if snr < 3.0:
       warnings.append("信噪比较低")
   ```

5. **缺失数据检查**:
   ```python
   missing_rate = np.sum(np.isnan(pv)) / len(pv)
   if missing_rate > 0.05:
       return False, "缺失数据超过5%"
   ```

6. **采样一致性检查**:
   ```python
   dt_std = np.std(np.diff(t))
   dt_mean = np.mean(np.diff(t))
   if dt_std > dt_mean * 0.5:
       warnings.append("采样间隔不一致")
   ```

7. **数据范围检查**:
   ```python
   if np.max(pv) > 1e6 or np.min(pv) < -1e6:
       return False, "数据范围异常"
   ```

8. **NaN/Inf检查**:
   ```python
   if np.any(np.isnan(pv)) or np.any(np.isinf(pv)):
       return False, "数据包含NaN或Inf"
   ```

### 4. 参数验证算法

**5层验证机制**:

1. **基本范围检查**:
   ```python
   if not (16.7 <= pb <= 200):
       warnings.append("pb超出推荐范围")
   if not (8 <= ti <= 120):
       warnings.append("ti超出推荐范围")

   ```

2. **参数比例关系检查**:
   ```python
   if td > 0 and ti / td < 4:
       warnings.append("Ti/Td比例过小，可能导致不稳定")
   if td > ti / 2:
       warnings.append("Td过大，建议 Td < Ti/2")
   ```

3. **特殊组合检查**:
   ```python
   kp = 100 / pb
   if kp > 3 and td > 10:
       warnings.append("高增益+大微分可能导致振荡")
   if ti < 15 and kp > 2:
       warnings.append("小积分时间+高增益可能不稳定")
   ```

4. **场景特定检查**:

   if scenario == 'temperature':

   elif scenario == 'level':

   elif scenario == 'flow':

5. **基于模型参数的检查**:

   if model_params:
       K, T, L = model_params['K'], model_params['T'], model_params['L']

### 5. 稳态检测算法

**多指标稳态判断**:

```python
def is_steady_state(pv, threshold_ratio=0.02, window_size=20):
    """
    基于多个指标判断是否稳态:
    1. 标准差检查
    2. 变化范围检查
    3. 趋势检查
    """
    # 1. 标准差检查
    pv_std = np.std(pv)
    pv_range = np.max(pv) - np.min(pv)
    if pv_std / pv_range > threshold_ratio:
        return False
    
    # 2. 变化范围检查
    if pv_range > threshold_ratio * np.mean(pv):
        return False
    
    # 3. 趋势检查（线性拟合斜率）
    t = np.arange(len(pv))
    slope = np.polyfit(t, pv, 1)[0]
    if abs(slope) > threshold_ratio * pv_range / len(pv):
        return False
    
    return True
```

### 6. 设定值变化检测算法

**检测逻辑**:

```python
def detect_setpoint_changes(sv, threshold=0.5):
    """
    检测设定值变化点并分段
    """
    changes = []
    current_sv = sv[0]
    
    for i in range(1, len(sv)):
        if abs(sv[i] - current_sv) > threshold:
            changes.append(i)
            current_sv = sv[i]
    
    # 生成分段
    segments = []
    start = 0
    for change_point in changes:
        segments.append((start, change_point))
        start = change_point
    segments.append((start, len(sv)))
    
    return segments
```
