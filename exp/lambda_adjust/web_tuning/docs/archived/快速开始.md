# 🚀 Web Tuning 快速开始指南

## 📋 两种运行模式

| 模式 | 用途 | OPC UA Server | 启动方式 |
|------|------|---------------|---------|
| 🧪 **仿真模式** | 开发测试 | 本地仿真服务器 | `./start_dev.sh` |
| 🏭 **生产模式** | 工业现场 | 真实 OPC UA Server | `./start_prod.sh` |

---

## 🧪 开发环境（仿真模式）

### 一键启动

```bash
# 终端1：启动仿真服务器
cd servers
python opcua_realistic_server.py

# 终端2：启动 Web Tuning 系统
cd backend
./start_dev.sh
```

### 手动启动

```bash
# 设置环境变量
export WEB_TUNING_ENV=development

# 启动应用
python app.py
```

### 验证

看到以下日志表示成功：

```
🧪 [配置] 加载开发环境配置 - 仿真模式
🧪 [仿真模式] 正在连接到仿真 OPC UA 服务器
✅ [仿真模式] OPC UA 连接成功 - 使用仿真数据
```

---

## 🏭 生产环境（真实工业系统）

### 一键启动

```bash
# 1. 配置生产环境（首次使用）
vim config/production.py
# 修改 endpoint_url、username、password

# 2. 启动系统
./start_prod.sh
```

### 手动启动

```bash
# 设置环境变量
export WEB_TUNING_ENV=production

# 启动应用
python app.py
```

### 验证

看到以下日志表示成功：

```
🏭 [配置] 加载生产环境配置 - 生产模式
🏭 [生产模式] 正在连接到工业 OPC UA 服务器
✅ [生产模式] OPC UA 连接成功 - 连接到真实工业系统
```

---

## 🔄 环境切换

```bash
# 切换到开发环境
export WEB_TUNING_ENV=development

# 切换到生产环境
export WEB_TUNING_ENV=production

# 查看当前环境
echo $WEB_TUNING_ENV
```

- ✅ 用于开发和测试

- ⚠️ 不要用于生产环境

- ✅ 连接真实 OPC UA Server

- ⚠️ 参数会直接写入 PLC/DCS

## 🆘 常见问题

### Q: 如何确认当前模式？

**A**: 查看启动日志：
- `🧪 [仿真模式]` = 开发环境
- `🏭 [生产模式]` = 生产环境

### Q: 仿真服务器必须启动吗？

**A**: 
- 仿真模式：必须启动
- 生产模式：不需要

### Q: 如何修改 OPC UA Server 地址？

**A**: 
- 开发环境：修改 `config/development.py`
- 生产环境：修改 `config/production.py`
