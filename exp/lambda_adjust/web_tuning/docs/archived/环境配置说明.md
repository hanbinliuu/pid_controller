# 🔧 Web Tuning 环境配置说明

## 📋 概述

Web Tuning 系统支持两种运行模式：

1. **🧪 仿真模式（Simulation）** - 用于开发测试
2. **🏭 生产模式（Production）** - 用于实际工业现场

同一套代码，通过配置文件和环境变量区分运行环境。

---

## ⚙️ 配置文件详解

### development.py（开发环境）

```python
OPCUA_CONFIG = {
    "mode": "simulation",                      # 仿真模式
    "endpoint_url": "opc.tcp://localhost:4840", # 本地仿真服务器
    "username": None,                           # 仿真服务器通常不需要认证
    "password": None
}
```

**特点**：
- ✅ 连接本地仿真服务器
- ✅ 无需认证
- ✅ DEBUG 日志级别
- ✅ 用于开发和测试

### production.py（生产环境）

```python
OPCUA_CONFIG = {
    "mode": "production",                           # 生产模式
    "endpoint_url": "opc.tcp://192.168.1.100:4840", # 真实 OPC UA Server
    "username": "admin",                             # 需要认证
    "password": "password"                           # 从环境变量获取
}
```

**特点**：
- ✅ 连接真实工业 OPC UA Server
- ✅ 需要认证
- ✅ INFO 日志级别
- ✅ 记录日志到文件
- ✅ 生产环境安全配置

## 🔒 生产环境安全建议

### 1. 密码管理

❌ **不要**：在代码中硬编码密码
```python
# 不要这样做！
"password": "my_password_123"
```

✅ **应该**：使用环境变量
```python
import os
"password": os.getenv('OPCUA_PASSWORD')
```

### 2. 证书管理

生产环境使用加密连接：

```python
SECURITY_CONFIG = {
    "opcua_security_policy": "Basic256Sha256",
    "opcua_security_mode": "SignAndEncrypt",
    "client_certificate": "/etc/web_tuning/certs/client_cert.pem",
    "client_private_key": "/etc/web_tuning/certs/client_key.pem"
}
```

### 3. 网络隔离

- 生产环境应在独立的工业网络中
- 使用防火墙限制访问
- 启用 VPN 或专线连接

## 📚 常见问题

### Q1: 如何确认当前运行模式？

**A**: 查看启动日志，会明确显示：
- `🧪 [仿真模式]` - 仿真环境
- `🏭 [生产模式]` - 生产环境

### Q2: 仿真服务器必须启动吗？

**A**: 
- **仿真模式**：必须先启动仿真服务器
- **生产模式**：不需要仿真服务器，直接连接真实 OPC UA Server

### Q3: 如何在生产环境测试？

**A**: 
1. 在测试环境部署一个真实的 OPC UA Server
2. 使用 `production` 模式连接
3. 不要在生产环境直接测试！

### Q4: 配置文件可以自定义吗？

**A**: 可以！复制 `production.py` 创建自定义配置：
```bash
cp config/production.py config/staging.py
# 修改 staging.py
export WEB_TUNING_ENV=staging
```
