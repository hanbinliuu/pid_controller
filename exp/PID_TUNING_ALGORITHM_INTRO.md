## 一、核心创新点

### 1.1 双路径自适应整定架构

传统 PID 整定只能处理单一类型数据，本系统创新性地实现了**双路径自适应架构**：

```
┌─────────────────────────────────────────────────────────────┐
│                      数据输入                                │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│              数据特征分析（振荡检测、质量评估）              │
│  • 振荡比 > 0.5 → 振荡数据                                  │
│  • 阶跃特征 > 0.4 → 正常数据                                │
│  • 模型 R² < 0.4 → 拟合失败                                 │
└─────────────────────────────────────────────────────────────┘
                           ↓
        ┌──────────────────┴──────────────────┐
        ↓                                      ↓
┌───────────────────┐                ┌───────────────────┐
│   模型辨识路径     │                │   振荡整定路径     │
│  (14/80 场景)     │                │  (66/80 场景)     │
├───────────────────┤                ├───────────────────┤
│ • FOPDT/FO/SO拟合 │                │ • 临界参数检测    │
│ • Lambda/SIMC整定 │                │ • Ku/Pu 提取      │
│ • 回路类型差异化   │                │ • Z-N 临界法整定  │
└───────────────────┘                └───────────────────┘
```

**价值**：无需人工判断数据类型，系统自动选择最优整定路径

---

### 1.2 回路类型差异化整定策略

**核心理念**：不同回路类型有天然不同的物理特性，应采用不同整定策略

| 回路类型 | 物理特性 | 整定策略 | 理论依据 |
|---------|---------|---------|---------|
| **Flow** | 快速响应 | SIMC（Ti 有上限） | 防止过快积分导致过冲 |
| **Level** | 积分特性 | SIMC（保守 τc） | 液位是积分过程，需限制 Ti |
| **Pressure** | 快速+非线性 | Lambda（保留微分） | 阀门非线性需要 Td 抑制 |
| **Temperature** | 慢速高阶 | Lambda（无 Ti 上限） | 热惯性大，允许较长 Ti |

**实现验证**：

```
Flow 场景:     Lambda Kp=2.47 → SIMC Kp=1.18 (降低52%)
Level 场景:    Lambda Kp=4.00 → SIMC Kp=2.46 (降低38%)
Pressure/Temp: 保持 Lambda 不变
```

### 1.3 多重安全机制

```
整定参数计算 → 闭环仿真验证 → 稳定性检查
                    ↓
              ┌─────┴─────┐
              ↓           ↓
           稳定         不稳定
              ↓           ↓
           输出      增加保守因子
                         ↓
                    重新整定
                    (最多3轮)
```

**渐进式保守调整因子**：

- 基础保守因子：根据数据质量 (0.8-1.2)
- 振荡保守因子：根据振荡强度 (1.0-2.5)
- 回路类型因子：Temperature/Level 额外 ×1.3-1.4
- 低置信度因子：模型 R² 低时增加保守度

## 二、核心整定算法

### 2.1 SIMC 整定法 (Skogestad IMC)

**来源**：挪威科技大学 Skogestad 教授，2003年发表

**核心公式**（FOPDT 模型）：

```
τc = T1 × tau_c_factor    (闭环时间常数)
Kp = T1 / (K × (τc + L))
Ti = min(T1, ti_limit_factor × (τc + L))   ← 关键创新：Ti 有上限
Td = 0
```

**优势**：
- 只需调节一个参数 τc
- Ti 上限约束防止慢系统积分过慢
- 适合积分过程和快速系统

### 2.2 Lambda 整定法

**核心公式**（FOPDT 模型）：

```
λ = T1 × lambda_factor
Kp = (T1 + L/2) / (K × (λ + L/2))
Ti = T1 + L/2
Td = T1 × L / (2×T1 + L)
```

**优势**：
- 经典 IMC 方法，理论成熟
- 保留微分项，适合需要阻尼的系统
- 适合慢速高阶系统

### 2.3 Z-N 临界法

**适用场景**：数据含明显振荡，模型辨识失败

**核心公式**：

```
Ku = 临界增益（从振荡数据提取）
Pu = 临界周期（振荡周期）

Kp = 0.45 × Ku
Ti = Pu / 1.2
Td = Pu / 8
```

## 三、测试验证结果

### 3.1 测试覆盖

**80 个模拟场景**，覆盖：

| 维度 | 覆盖范围 |
|------|---------|
| 时间常数 T1 | 5s ~ 250s |
| 增益 K | 0.3 ~ 2.0 |
| 滞后 L | 0.5s ~ 30s |
| 振荡强度 | 0.3 ~ 0.95 |
| 回路类型 | Flow/Level/Pressure/Temperature |

### 3.2 稳态达成率

| 回路类型 | 场景数 | 稳定数 | 稳态率 |
|---------|-------|-------|--------|
| Flow | 32 | 25 | **78%** |
| Level | 10 | 8 | **80%** |
| Pressure | 7 | 7 | **100%** |
| Temperature | 31 | 23 | **74%** |
| **总计** | **80** | **63** | **78.8%** |

### 3.3 与传统方法对比

| 方法 | 稳态率 | 适应性 |
|------|--------|--------|
| 固定参数 | ~40% | 差 |
| 纯 Lambda | 62/80 (77.5%) | 中 |
| 纯 SIMC | 59/80 (73.8%) | 中 |
| **混合策略** | **63/80 (78.8%)** | **强** |

## 四、系统配置

### 4.1 SIMC 配置

```python
SIMC_TUNING = {
    'enable': True,
    'tau_c_factor': 2.0,              # τc = T1 × 2.0
    'tau_c_min_factor': 2.0,          # τc >= L × 2.0
    'ti_limit_factor': 10.0,          # Ti <= 10 × (τc + L)
    'use_half_rule': True,            # 二阶系统半规则
    
    # 回路类型策略
    'loop_type_method': {
        'flow': True,         # SIMC
        'level': True,        # SIMC
        'pressure': False,    # Lambda
        'temperature': False, # Lambda
    }
}
```

### 4.2 振荡整定配置

```python
OSCILLATION_TUNING = {
    'ku_conservative_factor': 0.8,    # Ku 保守系数
    'ti_scale': 0.5,                  # Ti 缩放
    'pb_max': 500,                    # PB 最大值
    'decay_ratio_threshold': 1.2,    # 衰减比阈值
}
```
