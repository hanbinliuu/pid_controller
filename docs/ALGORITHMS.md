# PID Agent MVP 核心算法文档

## 1. 算法概览
本系统的算法核心位于 `core/algorithm/`，旨在通过被动或主动数据，实现对工业过程的精确建模与控制优化。

## 2. 核心模块详解

### 2.1 模型辨识 (Model Identification)
- **多模型支持**: 支持一阶滞后 (FOPDT)、二阶滞后 (SOPDT) 以及非稳态模型。
- **自动拟合**: 采用非线性最小二乘法 (`nonlinear_fitter.py`)，在时域内拟合 PV 曲线。
- **模型评价**: 通过残差分析与相关性评估 (`model_rating.py`)，为辨识出的模型打分，确保可靠性。

### 2.2 PID 整定逻辑 (PID Tuning)
- **Lambda 整定法**: 工业界最常用的鲁棒整定方法，通过设置闭环时间常数 $\lambda$ 来平衡响应速度与稳定性。
- **IMC (内模控制)**: 基于过程模型导出控制器参数，适用于具有明显纯滞后的过程。
- **临界比例度法 (Ziegler-Nichols)**: 针对出现明显震荡的回路，自动识别震荡周期与增益，应用临界整定公式。

### 2.3 性能分析指标 (Performance Metrics)
系统自动计算以下核心指标：
- **自控率**: 回路在自动模式下的运行时间占比。
- **稳定性**: PV 在 SP 附近的波动方差。
- **IAE/ISE**: 误差绝对值累积与平方累积。
- **震荡检测**: 利用自相关函数或零点交叉法检测回路是否处于受限震荡状态。

## 3. 闭环仿真验证
在给出建议参数前，系统会调用 `ClosedLoopSim` 进行仿真：
1. **输入阶跃响应**: 模拟 SP 阶跃变化。
2. **扰动响应**: 模拟外部干扰对系统的影响。
3. **指标预测**: 预测新参数下的超调量 (Overshoot) 和调节时间 (Settling Time)。

## 4. 实验性优化 (exp/lambda_adjust)
目前正在测试的新特性包括：
- **数据质量预检**: 在辨识前检查信噪比、激励程度等。
- **鲁棒性约束**: 在整定公式中加入稳定性裕量约束，防止参数过于激进。
